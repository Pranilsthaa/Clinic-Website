# Project Instructions: Chiropractor Clinic Website

## Overview
This is a Next.js project for a chiropractor clinic website.

## Technical Requirements
- **Framework**: Next.js (latest version) and React.
- **Database & API**: Use PostgreSQL and Next.js API routes for form handling and the admin panel.
- **Best Practices**: Strictly adhere to the latest best practices for both Next.js and React.
- **SEO**: The website must be highly SEO friendly (proper meta tags, semantic HTML, sitemaps, fast loading, etc.).
- **Architecture**: The folder structure should be perfect, scalable, and modular.
- **Components**: Use reusable components wherever necessary to maintain DRY (Don't Repeat Yourself) code.

## UI/UX Guidelines
- **Responsiveness**: Must be fully responsive across all devices (mobile, tablets, and PC).
- **Design Quality**: The UI should be pixel-perfect, modern, and highly professional.
- **Theme**: The website's color theme is **forest green and warm earth tones** (Primary: #005440, Accent: #1D9E75, Sand: #FAEEDA, Background: #fbf9f4).
- **Typography**: Libre Caslon Text (serif) for headlines, Manrope (sans-serif) for body text.
- **Design System**: "Human-Centric Wellness" — tactile minimalism with organic shapes, soft shadows, and generous whitespace.
